# Radar nowcast and tropical cyclones / เรดาร์เตือนฝนระยะสั้นและพายุหมุนเขตร้อน

The 6-hourly global model cannot tell you that a storm cell will reach your house in 25 minutes.
This is a separate, radar-based product: **"will it rain / storm at this point in the next hour, and when"**,
plus **"is a tropical cyclone coming"**. It is shown at the top of the point panel and as a radar
overlay on the map.

โมเดลโลกที่ออกทุก 6 ชั่วโมงบอกไม่ได้ว่ากลุ่มฝนจะถึงบ้านใน 25 นาทีหรือไม่ จึงมีผลิตภัณฑ์แยกต่างหากที่ใช้เรดาร์
ตอบว่า **"จุดนี้ฝนจะตกหรือมีพายุฝนฟ้าคะนองใน 1 ชั่วโมงข้างหน้าไหม ถึงเมื่อไร"** และ **"มีพายุหมุนเขตร้อนเข้าใกล้หรือไม่"**
แสดงที่ด้านบนของแผงรายจุด และเป็นชั้นเรดาร์บนแผนที่

## 1. Data sources and terms / แหล่งข้อมูลและเงื่อนไข

| Data | Source | Notes |
|---|---|---|
| Radar reflectivity | [RainViewer](https://www.rainviewer.com) free API, `weather-maps.json` | past frames every 10 min for 2 h; only colour scheme 2 ("Universal Blue") and zoom <= 7 are served; **100 requests/IP/min**; terms: *personal and educational use* |
| Radar coverage mask | RainViewer `/v2/coverage` tiles | transparent = covered, opaque black = no radar |
| Tropical cyclones | [GDACS](https://www.gdacs.org) event list + geometry API (republishing JTWC / NOAA / RSMC advisories) | refreshed every 30 min |

- **Attribution is mandatory.** The point panel shows "RainViewer, GDACS" and the radar overlay is tagged
  "RainViewer"; keep both if you embed the data elsewhere.
- **RainViewer's free tier is for personal and educational use.** A public, high-traffic deployment should
  check the current terms (or buy a plan) before leaving `THWX_NOWCAST_SOURCE=rainviewer` on. The backend
  fetches 8 tiles per new frame (zoom 6, ~2.4 km per pixel) plus one small JSON request every 5 minutes, which is
  far below the rate limit, and all visitors share one copy - the browser never calls RainViewer directly.
- Set `THWX_NOWCAST_SOURCE=off` to disable the radar part and `THWX_CYCLONES_ENABLED=false` to disable GDACS.

- **ต้องแสดงที่มาของข้อมูล** แผงรายจุดระบุ "RainViewer, GDACS" และชั้นเรดาร์มีป้าย "RainViewer"
- **แพ็กเกจฟรีของ RainViewer จำกัดการใช้เพื่อส่วนบุคคลและการศึกษา** หากเปิดให้คนจำนวนมากใช้ ควรตรวจเงื่อนไขล่าสุดหรือซื้อแพ็กเกจ
  ระบบดึงข้อมูลที่ฝั่งเซิร์ฟเวอร์เพียงชุดเดียวแล้วแบ่งให้ทุกคน (ไม่มีการเรียก RainViewer จากเบราว์เซอร์)
- ปิดเรดาร์ด้วย `THWX_NOWCAST_SOURCE=off` และปิดข้อมูลพายุด้วย `THWX_CYCLONES_ENABLED=false`

## 2. Method / วิธีการ

**Ingest** (`app/nowcast/radar.py`). RainViewer returns coloured PNG tiles, not reflectivity. With smoothing
off every integer dBZ has exactly one RGBA value, so the colour table is inverted
(`app/data/rainviewer_universal_blue.json`, generated by `scripts/build_rainviewer_palette.py` from RainViewer's
published CSV; 77 distinct colours because dBZ >= 65 share a few colours). Unknown opaque colours snap to the
nearest palette colour. Tiles are mosaicked and resampled (nearest) onto the 0.02 degree grid. Last 3 frames are kept.

**Motion** (`motion.py`). Block phase correlation (FFT, Hann window, sub-cell peak interpolation) between consecutive
frames in 96x96-cell blocks (stride 48) that contain >= 3 % echo >= 20 dBZ; vectors above 120 km/h are rejected; the
last two frame pairs are averaged, empty blocks take the median, the field is smoothed and interpolated to the grid.

**Point nowcast** (`nowcast.py`). The point is traced backwards through the motion field in 5-minute sub-steps; for
leads 0, 5, ... 60 min the latest frame's maximum dBZ within **5 km** of the traced position is what will be over the
point. ETA = first lead with >= 20 dBZ (rain) and >= 45 dBZ (thunderstorm). Repeating with the speed x0.8 and x1.25 gives
`minutes_range`. The reported class/dBZ is the peak within 20 minutes after arrival. Because of the 5 km radius the
ETA means "the echo reaches within 5 km", i.e. up to a few minutes earlier than the cell centre.

**Nearest cell.** The nearest echo >= 40 dBZ within 100 km: distance, bearing, class, and `approaching` when its motion
has a component toward the point greater than 5 km/h (`closing_kmh`).

**Map layer.** `/nowcast/layer?lead=0` is the latest frame (`uint8`, linear -10..75 dBZ, 0 = no echo); leads 10..60 min
are the same frame advected along the motion field (served, not yet shown in the UI).

**Cyclones** (`cyclones.py`). GDACS events with `iscurrent == true` and a track point within 1,500 km of 13 N 101.5 E.
Category from the event's peak wind: < 63 km/h depression (TD), 63-117 tropical storm (TS), >= 118 typhoon (TY). Track
points come from the `Point_Polygon_Point_N` rings (time label + year from `fromdate`), forecast flag and class from
the `Line_Line_N` segments, wind zones from the `Poly_*` rings labelled `60/90/120 km/h`. Distance now and closest approach
(from now on) use linear interpolation along the track; "in wind zone" is a point-in-polygon test against the strongest
swath containing the point. A failing event is skipped without affecting the others.

## 3. Classes / ระดับ

| dBZ | class | ภาษาไทย |
|---|---|---|
| < 20 | `none` | ไม่มีฝน |
| 20-29 | `light` | ฝนเล็กน้อย |
| 30-39 | `moderate` | ฝนปานกลาง |
| 40-44 | `heavy` | ฝนหนัก |
| 45-54 | `thunderstorm` | พายุฝนฟ้าคะนอง |
| >= 55 | `severe` | พายุฝนฟ้าคะนองรุนแรง (อาจมีลูกเห็บ/ลมกระโชกแรง) |

These are radar-based estimates; the UI says "likely" ("น่าจะ") and is **not an official warning**.

## 4. States / สถานะ

`available: false` with `reason`: `disabled` (source off), `no_data` (first frame not yet loaded), `stale` (newest frame
older than 30 min), `no_coverage` (point outside radar coverage). Cyclones are reported regardless of radar state. The last
good state is kept when an upstream request fails.

## 5. Limitations / ข้อจำกัด

- **Advection only - no growth or decay.** New cells are not predicted and dying cells keep their intensity; skill drops
  after about 30-60 minutes, which is why the horizon is one hour.
- Reflectivity is converted to a rain *class*, not a rain rate; hail and wind gusts are not measured.
- Radar gaps, beam blockage by mountains, anomalous propagation and the colour quantisation of the tiles add noise;
  only the 20 dBZ and above echoes are used.
- Resolution is ~2.4 km (zoom 6); small cells narrower than that are blurred.
- Cyclone positions are 6-hourly (interpolated linearly), the wind zones are the agency's forecast swaths, not a
  live wind analysis. Peak wind in the event list can include forecast intensity.
- RainViewer discontinued its nowcast and raw dBZ products on 2026-01-01, so extrapolation is done here.
- ไม่คาดการณ์การเกิดใหม่หรือการสลายตัวของกลุ่มฝน ความแม่นยำลดลงหลังประมาณ 30-60 นาที
- ใช้เป็นข้อมูลประกอบการตัดสินใจ ไม่ใช่ประกาศเตือนภัยอย่างเป็นทางการ ให้ติดตามประกาศของกรมอุตุนิยมวิทยา

`category` is the storm's **current** intensity (class of the latest non-forecast track point; falls back to the peak wind if unknown); `peak_category` comes from GDACS's peak wind, which can include the forecast, and the UI adds "may strengthen" when it is stronger. / `category` คือความรุนแรงปัจจุบัน ส่วน `peak_category` คือจุดสูงสุดตามพยากรณ์
