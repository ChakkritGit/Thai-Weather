## API

No key; 60 requests/min and 5,000/day per IP; JSON; CORS enabled. Base URL @THWX_0@/api/v1. Endpoints: /point?lat=&lon= (hourly 2.2 km forecast), /provinces, /provinces/{id}, /alerts?min_severity=1..3, /nowcast?lat=&lon=, /meta. Schema: @THWX_1@/api/v1/openapi.json.
