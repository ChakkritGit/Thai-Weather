# ตรวจความปลอดภัย

1. เรียก `security` (days 30) ถ้าถามถึง IP ใด ให้ใส่ `ip` ด้วย
2. เรียก `attacks` (days 7 หรือตามที่ถาม)
3. ดูว่า
   - มีล็อกอิน SSH หรือหน้าแอดมินจากเครือข่ายใหม่ไหม บอกเวลา IP และเครือข่ายให้ครบ
   - SSH หรือรหัสผ่านหน้าแอดมินผิดเยอะผิดปกติไหม และมาจาก IP ไหน
   - เหตุการณ์ระดับร้ายแรงหรือเตือน เช่น ไฟล์ใหม่ใน /etc พอร์ตใหม่ ผู้ใช้ใหม่
4. ตอบสั้น ๆ: ปกติหรือน่าสงสัย พร้อมเหตุผลทีละข้อ
5. ถ้าน่าสงสัย แนะนำสิ่งที่เจ้าของทำเองได้ เช่น เปลี่ยนรหัสผ่าน ลบกุญแจ SSH ที่ไม่รู้จัก หรือบล็อก IP
   ห้ามบอกว่าทำให้แล้ว เพราะเครื่องมือทุกตัวอ่านได้อย่างเดียว

การโจมตีจากอินเทอร์เน็ต (เดารหัส SSH สแกนพอร์ต) เป็นเรื่องปกติของเซิร์ฟเวอร์สาธารณะ
อย่าตกใจถ้าไม่มีล็อกอินสำเร็จจากที่ไม่รู้จัก
