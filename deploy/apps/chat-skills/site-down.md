# เว็บล่มหรือช้า

1. เรียก `services` ดูว่าบริการไหนล่ม ตั้งแต่เมื่อไร และสาเหตุที่หน้าสถานะเห็น
2. เรียก `containers` หาคอนเทนเนอร์ที่ไม่ได้ทำงาน unhealthy หรือเพิ่งรีสตาร์ต (Up ไม่กี่นาที)
3. เรียก `server_status` (range 1h) ดู CPU แรม ดิสก์ และคำขอ 5xx ของเว็บนั้น
4. ถ้าเป็นเว็บเดียว เรียก `web_traffic` (days 1, host ของเว็บนั้น) ดูว่าคนเข้าลดลงตอนไหน
5. ตอบ:
   - อะไรล่ม ตั้งแต่เมื่อไร
   - สาเหตุที่น่าจะเป็นจากข้อมูล (แยกให้ชัดว่าอะไรเห็นจริง อะไรคาดเอา)
   - สิ่งที่เจ้าของทำได้ใน Dock เช่น ดู log ของคอนเทนเนอร์นั้น หรือรีสตาร์ต
6. ถ้าทุกอย่างปกติจากฝั่งเซิร์ฟเวอร์ บอกตรง ๆ และให้ลองจากเครือข่ายอื่น
   เพราะอาจเป็นที่ Cloudflare DNS หรือเครือข่ายของผู้ใช้
