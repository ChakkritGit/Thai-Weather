# สรุปรายเดือน

1. เดือนนี้อยู่ในข้อมูลของระบบแล้ว ถ้าถามเดือนอื่นหรือให้เทียบ ให้เรียก `month_report` (month เป็น YYYY-MM)
   ทีละเดือน เช่น เดือนก่อนของเดือนนี้
2. ตอบเป็นหัวข้อสั้น ๆ:
   - uptime และเหตุขัดข้อง
   - CPU แรม ดิสก์ (เฉลี่ยและสูงสุด) และแนวโน้มดิสก์
   - ผู้เข้าชม และเว็บที่คนเข้ามากสุด
   - แบ็กอัป
3. ถ้าเทียบสองเดือน บอกเฉพาะที่เปลี่ยนชัด เป็นตัวเลขและเปอร์เซ็นต์
4. ปิดท้ายด้วยข้อแนะนำไม่เกิน 3 ข้อ ถ้าไม่มีอะไรน่าห่วง บอกว่าปกติ
