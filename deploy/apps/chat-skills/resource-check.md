# ตรวจทรัพยากรเครื่อง

1. เรียก `server_status` (range 1h) ดูตอนนี้ และ (range 24h หรือ 7d) ดูแนวโน้ม
2. เรียก `containers` ดูว่าคอนเทนเนอร์ไหนใช้ CPU หรือแรมมากสุด
3. ถ้าดิสก์เกิน 80% เรียก `backups` ดูขนาดแบ็กอัป เพราะเป็นตัวกินที่ที่พบบ่อย
4. ตอบ:
   - ตอนนี้หนักไหม เทียบกับปกติ (ค่าเฉลี่ย 24 ชั่วโมงหรือ 7 วัน)
   - ตัวที่กินมากสุด 3 อันดับ
   - steal สูงแปลว่าเครื่องเสมือนถูกแบ่ง CPU จากผู้ให้บริการ iowait สูงแปลว่ารอดิสก์
5. แนะนำสิ่งที่ทำได้ เช่น รีสตาร์ตตัวที่แรมโตผิดปกติ ล้างอิมเมจเก่าใน Dock หรือลบแบ็กอัปเก่า
   ห้ามบอกว่าทำให้แล้ว
